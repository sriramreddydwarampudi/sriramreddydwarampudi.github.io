ICDAS stands for International Caries Detection and Assessment System.


The ICDAS uses a two-stage process to record the status of the caries lesion. The first is a code for the severity of the caries lesion and the second is for the restorative status of the tooth. The status of the caries severity is determined visually on a scale of 0–6: 
• 0 = sound tooth structure
• 1 = first visual change in enamel
• 2 = distinct visual change in enamel
• 3 = enamel breakdown, no dentine visible
• 4 = dentinal shadow (not cavitated into dentine)
• 5 = distinct cavity with visible dentine
• 6 = extensive distinct cavity with visible dentine 


This severity code is paired with a restorative/sealant code 0–8: 
• 0 = not sealed or restored 
• 2 = sealant, partial 
• 3 = sealant, full; tooth-coloured restoration 
• 4 = amalgam restoration 
• 5 = stainless steel restoration 
• 6 = ceramic, gold, porcelain-fused-to-metal (PFM) crown or veneer
• 7 = lost or broken restoration 
• 8 = temporary restoration
