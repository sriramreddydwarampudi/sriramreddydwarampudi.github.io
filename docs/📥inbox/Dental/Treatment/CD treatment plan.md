#### Soft Palate
• Class I: Normal treatment protocol should be followed.
• Class II: The posterior palatal seal should be recorded
more accurately with care.
• Class III: measures should be taken to prevent gag reflex
and the posterior palatal seal should be recorded more
accurately with care.


#### Hard palate
• U shaped: Normal treatment protocol should be
followed.
• V shaped: The mid palatine raphae should be relieved
during impression making procedures. The posterior
palatal seal should be recorded more accurately with
care.
• Flat: The posterior palatal seal should be recorded more
accurately with care. The secondary impression should
be made passively. Arbitrary cast scrapping techniques
should be followed
