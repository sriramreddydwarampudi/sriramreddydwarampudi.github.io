# Logical Operators and Their Mathematical Representations

## 1. Negation (NOT)
- **Propositional Logic:**  
  ¬P  
- **Arithmetic/Boolean Representation:**  
  1 - P  
- **Set-Theoretic Analogy:**  
  Complement of a set, P^c  

## 2. Conjunction (AND)
- **Propositional Logic:**  
  P ∧ Q  
- **Arithmetic/Boolean Representation:**  
  P * Q  
- **Set-Theoretic Analogy:**  
  Intersection, P ∩ Q  

## 3. Disjunction (OR)
- **Propositional Logic:**  
  P ∨ Q  
- **Arithmetic/Boolean Representation:**  
  P + Q - P * Q  
  (Alternative: max(P, Q))  
- **Set-Theoretic Analogy:**  
  Union, P ∪ Q  

## 4. Implication (IF…THEN)
- **Propositional Logic:**  
  P → Q  
- **Arithmetic/Boolean Representation:**  
  1 - P + P * Q  
- **Explanation:**  
  The implication is true except when P = 1 and Q = 0.  

## 5. Biconditional (IF AND ONLY IF)
- **Propositional Logic:**  
  P ↔ Q  
- **Arithmetic/Boolean Representation:**  
  1 - P - Q + 2P * Q  
  (Alternative: 1 - (P - Q)^2)  
- **Set-Theoretic Analogy:**  
  (P ∩ Q) ∪ (¬P ∩ ¬Q)  

## 6. Exclusive OR (XOR)
- **Propositional Logic:**  
  P ⊕ Q  
- **Arithmetic/Boolean Representation:**  
  P + Q - 2P * Q  
- **Set-Theoretic Analogy:**  
  (P ∪ Q) \ (P ∩ Q)  

## 7. NAND (Sheffer Stroke)
- **Propositional Logic:**  
  ¬(P ∧ Q)  
- **Arithmetic/Boolean Representation:**  
  1 - P * Q  

## 8. NOR (Peirce Arrow)
- **Propositional Logic:**  
  ¬(P ∨ Q)  
- **Arithmetic/Boolean Representation:**  
  1 - (P + Q - P * Q) = 1 - P - Q + P * Q

Propositional logic statement:  P -> Q (If P then Q)

Mathematical equivalent:  P < Q(in Boolean algebra, if P is true, Q must also be true)
